# HeartToHeart4-zh-TW
為HeartToHeart4增加繁體中文選項

使用步驟：
1.用原文安裝檔的 setup.exe 安裝 HeartToHeart4，然後關閉程式。
2.打開安裝資料夾：在桌面捷徑按右鍵 →「開啟檔案位置」。
*預設路徑：C:\Program Files (x86)\HeartToHeart4(V2.4.0)
3.把繁中補丁中的 HeartToHeart4.exe、zh-TW、ToolBox、backup_original 複製進去，遇到同名檔案選「取代」。
4.開啟程式 → 選單「Language」→「繁體中文」→ 依提示重新啟動軟體。

*原版「HeartToHeart4.exe」放在backup_original資料夾中，複製回去即可還原。
